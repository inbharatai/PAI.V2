## What was broken, now fixed

1. **Shipped binary had no frontend (the "localhost refused to connect" class).**
   Root cause found at `tauri-macros`: `generate_context!` embeds ZERO assets
   unless the crate enables `tauri/custom-protocol`. `cargo build --release`
   never did. `custom-protocol` is now a default feature; the byte-level gate
   proves embedding in CI and against the staged drive binary.
2. Recording privacy levels lied (TRANSCRIPT_ONLY/SUMMARY_ONLY kept audio; STT
   never ran; zero-samples reported success) — fixed with a policy crate +
   delete-verified temp WAV + truthful outcomes; SUMMARY_ONLY disabled in UI.
3. Browser was a script-execution hole that lied about success — rewritten to
   typed, executed, verified actions with scheme allowlist, JSON-literal
   escaping, confirmation gating, real screenshots.
4. Agent: unmeasured confidence silently became 1.0; repeated calls looped;
   malformed calls executed — schema validation + circuit breaker + deadline
   + Option<f32> confidence.
5. Vault: setup could silently re-initialise and clobber identity — now
   transactional, byte-preserving, refusals tested.
6. Mobile: dead detection path (silently looked broken), Room store as
   plaintext permanent store, WAKE_LOCK never used — honest detection with
   mandatory reasons, TTL + clear-on-detach cache, permission removed.
7. Manifest writer emitted UTF-8 BOM rejected by the native verifier (staging
   rollback repro'd it) — BOM-free write.
