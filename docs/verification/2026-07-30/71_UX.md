# 71 — UX review

## Truthfulness-driven UX changes this cycle

- **RecordingView**: `SUMMARY_ONLY` option is now disabled with the explicit
  label "Summary Only — unavailable (summarisation not implemented)" instead
  of silently discarding audio while implying a summary. The stop outcome
  (what persisted, warnings, plain-language message) is surfaced in the UI,
  previously dropped.
- **BrowserWorkspace**: results now show `OK (verified=…)`, real current URL/
  title, real screenshot path + SHA-256, or `FAILED: <reason>`. Risky actions
  get an explicit consent dialog. The "Execute Script" free-text button is
  gone (it was arbitrary script injection).
- **ChatView**: new `InvalidToolCall` step pill (yellow) distinguishes
  schema/repetition rejections from safety blocks.
- **UnlockScreen**: carries the dev-bypass wiring (gated: feature + env var).

## Verified live

Packaged app from the drive opens a window titled "UnoOne Power" (55). Vault
lock/setup screens are reachable — deeper UX journeys are human-gated.

## Not changed

Nothing marketing-ish was added. UI copy claims that were false ("Summarization:
Gemma 4 12B — intelligent summarization") were replaced with truthful text.
